# 👑 Muhavra Master — Game Website

Hindi muhavare emojis me! Ek free browser game: 3 levels, 30 muhavare, timer, hint, 50-50 lifeline, score + WhatsApp share.

## Files
- `index.html` — game (sab kuch ek file me; koi server nahi chahiye)
- `about.html` — About page (AdSense approval ke liye zaroori)
- `privacy.html` — Privacy Policy page (AdSense approval ke liye zaroori)

## Deploy kaise karein (FREE)

### Option 1: Netlify Drop (sabse asaan)
1. https://app.netlify.com/drop kholo (free account banao)
2. Is poore folder ko drag karke page par chhod do
3. Site live! Ek free URL mil jayega (jaise `emoji-muhavra.netlify.app`)

### Option 2: GitHub Pages
1. GitHub par nayi public repo banao (jaise `emoji-muhavra`)
2. Teeno HTML files upload karo
3. Repo Settings → Pages → Source: main branch → Save
4. Site `https://prabhakar0007.github.io/emoji-muhavra/` par live hogi

## AdSense ke steps
1. Pehle site ko ek **custom domain** se jodo (jaise `emojimuhavra.in` — domain ~₹500-800/saal) — free subdomain par approval mushkil hota hai.
2. 2-4 hafte site chalao, Kahani House channel + social media se traffic lao.
3. https://adsense.google.com par apply karo.
4. Approval ke baad, `index.html` me jahan `ad-slot` wale dashed box hain, wahan apna AdSense ad code paste kar do (boxes ko ad code se replace karna hai).
